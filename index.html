    3. The underlying local video studio is still in progress and is not included as a runnable public codebase here.

    4. When the application source is released, setup will be documented here with the required Python, Node.js, models, and ComfyUI versions.

    This page is intentionally clear about the boundary between the public showcase and the private application work.
